	It can contain one character, part of a word, an entire word, or even a sequence of words.

Key point: Token size is not fixed at 4 characters or 1 word. 
	The often-used approximation of 1 token ≈ 4 English characters is an average, not a tokenization rule.

	prompt  : 
		A prompt is an instruction, question, or input given to an AI model (such as ChatGPT) to generate a response.

	Token . : A token is the smallest unit of text processed by a Large Language Model (LLM). It can be a word, part of a word, punctuation mark, or symbol.
				approx : 4 char = 1 token 
				token size is not fixed 
				every model size diff cost 

				Input tokens: Tokens sent to the AI in your prompt.
				Output tokens: Tokens generated by the AI in its response.

				Why are tokens important?
					 Cost: API usage is generally billed based on input and output tokens.
					Context window: Determines how many tokens the model can handle within its context.
					Performance: More generated tokens generally require more processing time.

	Tokenization 

	Temperature :
		Temperature is a parameter in a Large Language Model (LLM) that controls the randomness and creativity of generated responses.
				Low temperature: More predictable, consistent, and focused responses.
				High temperature: More varied, creative, and less predictable responses.
	Top -k : 
				what is Python ? 
				10 Answers 
					top -1 
				Top-K is a text-generation sampling technique that limits the AI model to the K most probable next tokens.

				In simple words, Top-K tells the AI how many possible next tokens it can consider before selecting one.


	Hallucination   : 
			Hallucination is when an AI model generates incorrect, misleading, or completely fabricated information and
			 presents it as if it were true.


			Example 1: Personal information
				Prompt: What is Thaneshwara's height?

				Hallucinated answer: Thaneshwara's height is 5 feet 9 inches.

				Correct answer: I don't have verified information about Thaneshwara's height.

	how to reduce the Hallucination ? 


		1. Prompt Engineering	 : Give clear, specific instructions
		2. Low Temperature	 : Reduce randomness in generated responses------- Accurate 
		3. RAG			 : Retrieve information from trusted documents






	Context Window  :	What the LLM can process in the current request.

		Context Window is the maximum number of tokens an LLM can process in a single request,

		, including the user prompt, previous conversation, system instructions, documents, and generated response.


		

	Fine Tuning  : we are train up the model 
			Fine-Tuning is the process of taking an already trained Large Language Model (LLM) and 
			training it further with a specific dataset to make it better at a particular task, domain, or response style.
